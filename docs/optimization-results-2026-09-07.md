## 完成结果

| 范围 | 结果 |
|---|---|
| F1 下一集语义 | 历史 90% 进度显示“本集接近看完”，操作为“查看选集”；详情根据最新线路和可靠匹配决定是否有下一集。电影、末集、缺集和未知片目不再直接旧索引 +1；当前线路追平不宣称全剧完结。 |
| F2 播放中换源 | 优先唯一标准化集名，再按完整普通集号匹配；预告、特别篇、上下部、日期不混作普通集数。无法匹配时展示手动选集，取消保持原选择。相同集保留播放位置，其他集从头开始；旧播放器回调不能写到新选择。 |
| F3 集数 | 选中数据源显示当前线路集数和线路数量；其他源只显示线路数量，避免把重复线路相加。两条 12 集线路验证为“12 集 · 2 条线路”。 |
| F4 错误恢复 | 媒体错误仅提供重试、返回，以及存在备选时的换源/线路；不把跳集包装成恢复。错误面板支持小屏大字体下滚动。 |
| F5 续播与完整历史 | 首页提供最近一条续播摘要和“全部记录”；无记录隐藏摘要。收藏默认直接显示收藏，观看记录独立到达并支持本地片名搜索，无 10 条截断。 |
| F6 删除撤销 | 保留左滑删除，增加显式删除按钮及 Snackbar 撤销；恢复原集数、位置和时间。若已经有新记录则不覆盖。全部清空仍需确认，收藏不受影响。 |
| F7 搜索反馈 | 显示成功/失败源数量及结果可能不完整的提示；分页继续保留已有结果和失败源状态，计数不混用本次分页源数与全部源数。 |
| 详情与长剧 | 主播放入口位于海报信息前；选集在简介前，简介可展开。集名/集号搜索、正倒序或原序/反向排列、当前集定位均保留真实播放索引和特别篇原文。 |
| 无障碍与适配 | 集数提供单选角色和选中状态，数据源及导航提供 Tab 角色；进度条提供进度与 SetProgress 操作。小屏/低高度首页整体可滚动。 |
